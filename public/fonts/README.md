# Local fonts

The site uses locally hosted Latin subsets from Google Fonts, with `font-display: swap`.

- `cormorant-regular.woff2`: Cormorant Garamond, upright, weight 400.
- `cormorant-italic.woff2`: Cormorant Garamond, italic, weight 400.
- `inter-latin.woff2`: Inter, upright, variable weight.

Source metadata is retained in `google-fonts-source.css`. The font files use the SIL Open Font License; see `OFL-Cormorant-Garamond.txt` and `OFL-Inter.txt`.

Families: https://fonts.google.com/specimen/Cormorant+Garamond and https://fonts.google.com/specimen/Inter.
